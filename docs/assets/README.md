# Identity mark — icon only

The mark is a leaf cut into three loose pieces; the middle piece is an exact
Reuleaux triangle. Two colours: ink `#16181A`, accent `#E8500F`, paper `#F2F1ED`.

| File | Use |
|---|---|
| `mark.svg` | vector master (single source of truth) |
| `mark_512.png` | raster master |
| `mark_transparent.png` | RGBA, transparent background |
| `mark_mono_black.png` | single colour, for stamp / screen print |
| `mark_white_on_dark.png` | reversed, for dark backgrounds |
| `avatar_1024.png` | square crop for repository avatar / org icon |
| `social_preview.png` | 1280x640 social preview card |

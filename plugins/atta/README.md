# Atta v1.1 — ZCode plugin

This is the ZCode-native shell around the `atta` MCP server. It carries:

- `.zcode-plugin/plugin.json` — manifest (skill + MCP)
- `.mcp.json` — generated by `python3 -m atta.agent.install zcode-plugin`
  (contains this checkout's absolute paths; ignored by git)
- `.mcp.json.example` — template for a manual install
- `skills/atta-modeling/SKILL.md` — routing rules for the ten tools

## Install

From the repo root:

```bash
python3 -m atta.agent.install zcode-plugin
```

Then in ZCode:

1. **Plugin Marketplace → Add → Add Plugin Marketplace**
2. Paste the repo's `plugins/` directory
3. **Personal → dev-atta-local → Atta v1.1 → Install**
4. Start a new task; the `atta-modeling` skill and `mcp__atta__*` tools are
   available.

If the standalone `mcp.servers.atta` entry from
`python3 -m atta.agent.install zcode` is still enabled, keep only one of the two
to avoid duplicate tool listings.

## What the plugin does not do

It does not copy the geometry kernel and it does not change Atta's rules:
`pass` only means `verdict == "pass"`, a preview is not a verdict, and a
tessellated mesh is never passed off as a STEP B-rep.
